## Product Overview
**One-liner:** 관심종목 · 미국·한국 주식 RSI·매수존 자동 분석 (홈 `<title>`, OG title)

**What it does:** 검색한 미국·한국 주식의 RSI·이동평균(50/200)·매수존(-10~-25%)·밸류에이션을 무료 실시간 데이터로 자동 계산하는 모바일 PWA. 공포탐욕지수·10년물 금리·환율 매크로 지표 포함. (홈 meta description 원문)
여기에 더해 하단 탭바로 이동하는 두 도구가 있다.
- **판독기**(`/reader`): 역발상·차트·주가 판독기, 적정주가 계산, 몰빵지수 (페이지 제목)
- **자산 분배**(`/allocate`): 총 자산과 비율을 넣으면 배분 금액과 매수 주수(소수점 매수 기준)를 계산

**Product category:** 주식 지표 자동 분석 도구 / 자산 분배 계산기. 사이트가 스스로 쓰는 키워드: "미국 주식 분석, 한국 주식 분석, 국장, 삼성전자 RSI, RSI 계산, 이동평균선 50 200, 매수존, 밸류에이션, 공포탐욕지수, 주식 PWA, stock analyzer" (홈 meta keywords)

**Product type:** 모바일 PWA(웹앱). 사이트명 "관심종목", 영문 별칭 "popol" (JSON-LD), 언어 ko.

**Business model:** 이용 무료로 보임(가격·결제 화면 없음). 회원가입·로그인 없음. Google AdSense 광고 게재 (`/privacy`). 유료 플랜 여부는 **미확인**.

## Differentiation
페이지에서 확인되는 특징(경쟁사 대비 우위인지는 미검증):
**Key differentiators:**
- 미국장·국장을 한 앱에서 탭으로 전환 (홈 "미국장 / 국장")
- 무료 실시간 데이터 기반 자동 계산, 모든 종목에 같은 공식 적용 (`/stock/AAPL`)
- 매수존을 고점 대비 -10/-15/-20/-25% 가격으로 바로 제시
- 종목 화면에서 50일·200일 이격도에 따라 "🟢 정상", "🔴 강과열 · 매도 고려" 같은 신호를 표시
- 시장 심리(역발상)·지수 흐름(차트) 판독기를 점수와 한 줄 해석으로 제공 ("기대가 커진 상태예요. 새로 사기보다 팔 계획을 세워 둘 때입니다.")
- 자산 분배에서 소수점 매수 기준 주수 계산, ₩/$ 표시 전환
- 회원가입·로그인 없음, 입력값은 이 기기(localStorage)에만 저장하고 서버로 보내지 않음 (`/privacy`)
- 모바일 PWA
**How we do it differently:** 공개 시장 지표를 "정해진 구간에 따라 점수로 바꾼" 방식 (`/reader` 고지문)
**Why that's better:** **미확인** (사용자 검증 자료 없음)
**Why customers choose us:** **미확인**

- "총 자산을 넣고 종목을 검색해 추가하세요. 비율대로 배분 금액과 매수 주수(소수점 매수 기준)를 계산합니다." (`/allocate`)
**Words to use:** 국장, 미국장, 매수존, 이격도, 공포/광기, 과열, 몰빵지수, 판독기, 자동 계산, 무료 실시간 데이터 (사이트에서 쓰는 용어)
**Words to avoid:** "매수 권유·추천"으로 읽히는 표현 — 사이트가 "매매 권유가 아니며"라고 고지하므로 마케팅 문구도 이와 충돌하면 안 된다.
**Glossary:**
| Term | Meaning (페이지 기준) |
|------|---------|
| 매수존 | 52주 고점 대비 -10%·-15%·-20%·-25% 가격대 |
| RSI(14) | 14일 상대강도지수 |
| 단기(50일)·장기(200일) | 이동평균선과 현재가의 이격도(%) 및 신호(정상·강과열 등) |
| 추세 | 예: "골든크로스 영역" |
| 매크로 레짐 | 공포탐욕지수·10년물 금리·HY 스프레드로 본 시장 상태(예: fear). 미국장 탭에만 표시 |
| 역발상 판독기 | Bull-Bear Spread·풋콜비율·VIX·신용융자 증가율·하이일드 스프레드 5개 지표로 투자 심리 점수화 |
| 차트 판독기 | S&P 500의 200일/50일선 위 종목 비율·이격도(200일)·RSI(14)로 지수 과열/침체 점수화 |
| 밸류에이션 | PER·PSR·PBR·ROE 4개 항목 통과 여부 ("0/4 통과") |
| 몰빵지수 | 판독기 내 탭. 세부 정의는 이번에 읽은 화면에서 미확인 |
| 적정주가 계산 | 판독기 내 기능. 세부 정의는 이번에 읽은 화면에서 미확인 |
